## Still outstanding before any production approval
- **3D models**: believable interior + real vacuum shell and rigged characters; current model still looks like product prototype rather than studio-grade machinery. No material/lighting-only fix can make crude geometry premium.
- **Fur helmet**: needs proper fabricated fursuit look, soft dense fur groom, sane eye placement and visually obvious wearable neck opening. Current fox design is simplified low-poly.
- **World continuity**: need continuous room, distinct camera setups/technical cuts per 1.5–3 s. Current full animation contains excessive repeated set angles.
- **Mechanism**: actual brush roller should touch fur on a plausible carpet, airflow direction/physical pressure/centrifugal separation should be legible and no teleporting debris.
- **QA**: inspect motion sequences not just isolated stills; frame-to-frame element movement, collisions, caption legibility and cutaway transparency before final render.
- **Approval**: full low-quality preview must be approved by user before any high-resolution final render/publishing.

Recommendation for next modeler: stop changing sphere/box proportions in low-poly placeholders as sole improvement. Build detailed PBR glTF assets with real mesh topology/textures, reuse procedural Three.js for deterministic genuine movement, and gate with saved frame-sequence QA.
